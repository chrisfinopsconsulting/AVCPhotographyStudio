Privacy Policy — AVC Photography Studio Analytics Tool
Last updated: 28 September 2026

What this application is
This is a private, single-user reporting tool. It is operated by the owner of the AVC Photography Studio Pinterest account and the AVCPhotographyStudio Etsy shop, for the sole purpose of recording that account's own performance metrics in a spreadsheet stored on the owner's personal computer.

It is not a product, not a service, and is not offered to, installed by, or available to any other person. There are no other users and no user accounts.

What data it accesses
Using read-only Pinterest API scopes (user_accounts:read, pins:read, boards:read), the application reads only the operator's own Pinterest account data:

Aggregate account metrics: impressions, engagements, saves, pin clicks, outbound clicks, audience counts, follower and following counts, monthly views
Metadata for the operator's own pins and boards: identifiers, titles, board names, creation dates, destination links
Per-pin performance metrics for the operator's own pins
The application requests no write permissions. It does not create, modify, schedule or delete pins, boards or any other Pinterest content.

Whose data it does not access
The application does not access, collect, request, store or process personal data belonging to any other Pinterest user. It does not read other users' profiles, followers, boards, pins, comments or messages. It does not collect the identities of people who view or interact with the operator's pins — only anonymous aggregate counts that Pinterest itself reports.

How data is stored
All retrieved data is written to a Microsoft Excel workbook and to local JSON files on the operator's own Windows computer. Nothing is uploaded to any server, database, cloud service or third party.

Pinterest credentials are stored only as Windows environment variables on that computer. They are never written into configuration files, source code or any document, and are never transmitted anywhere other than to Pinterest's own authentication endpoint.

How data is shared
It is not shared. No data obtained through the Pinterest API is sold, rented, published, transferred, disclosed to any third party, or used for advertising, profiling or any purpose beyond the operator's private business reporting.

Retention and deletion
Data is retained locally for as long as the operator finds it useful, and can be deleted at any time by deleting the local files. Revoking the application's access in Pinterest account settings immediately and permanently ends all further data access.

Children
The application is not directed at children and collects no data from anyone.

Changes
Any change to this policy will be reflected on this page with an updated date.
